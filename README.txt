APK olish (bepul, kompyuterga hech narsa o'rnatmasdan):
1. github.com da akkaunt oching va yangi repository yarating (Public yoki Private).
2. Shu papkadagi BARCHA fayllarni (www, .github, package.json, capacitor.config.json) repository'ga yuklang ("Add file > Upload files").
   Diqqat: .github papkasi ham yuklansin.
3. Repository'da "Actions" bo'limiga kiring. "Build APK" ishga tushadi (5-8 daqiqa).
4. Tugagach, ish ichida pastdagi "Artifacts" dan "Tizim-APK" ni yuklab oling (zip ichida app-debug.apk).
5. APK'ni telefonga o'tkazing va oching. "Noma'lum manbalardan o'rnatishga ruxsat" so'raladi, ruxsat bering.
